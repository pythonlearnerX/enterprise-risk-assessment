## 二、本轮改动

### 1. 新增 `risk_app/decorators.py`

```python
def admin_required(view_func):
    @wraps(view_func)
    def _wrapped(request, *args, **kwargs):
        if not request.user.is_authenticated:
            return redirect_to_login(request.get_full_path())   # 未登录 → 登录页（带 next）
        if not is_admin(request.user):
            raise PermissionDenied("需要管理员权限")             # 已登录无权限 → 403
        return view_func(request, *args, **kwargs)
    return _wrapped
```

与 `user_passes_test` 的区别：**区分“未登录”和“无权限”**。前者跳登录，后者给 403，
普通用户不会再被反复要求登录。

### 2. 新增自建管理后台 `/console/`

- 4 张 KPI：企业总数、高风险、系统账号、AI 解读记录；
- 6 个入口：用户与角色、AI 解读记录、预警订阅、A/B 实验、分析看板、数据后台（Django Admin）；
- 系统状态表：数据库连接、数据规模、AI 可用账号、预警规则数、实验数、最近审计时间；
- 最近 10 条 `AuditLog`。

与管理相关的路由：`/console/`（自建）、`/admin/`（Django 自带）、`/manage/users/`、`/manage/ai-insights/`。

### 3. 新增 `templates/403.html`

深色卡片 + 403 + 三个出口（首页 / 企业信息 / 换账号登录）。

### 4. 菜单修正

- 「企业可视化」「风险可视化」补 `active` 判断；
- 「后台管理」拆成「管理后台」（自建，`/console/`）与「数据后台」（Django Admin，新窗口）；
- 管理组顺序：管理后台 → 用户管理 → AI 解读记录 → 数据后台。

### 5. 权限收口

`manage_users`、`ai_insights`、`ab_toggle` 全部改用 `@admin_required`，
异常路径统一走 403 页面。

## 五、说明

- 「数据后台」保留 Django Admin，用于批量改数据；「管理后台」是自建的业务运维页。
  老师若问“为什么两个”，答：Django Admin 改数据方便但对普通用户权限粒度粗，
  自建后台只暴露业务需要的入口，权限由 `admin_required` 统一控制。
- 菜单最多两层是刻意的：分组标题不可点，一级项才跳转，避免三级下拉在深色侧栏里难操作。

## 六、追加：企业对比页改为页内直接选企业（同日）

### 问题
原流程要先去「企业信息」一页页勾选，再点「对比选中」；而且企业列表的勾选框提交的是
`?ids=1&ids=2&ids=3`（同名多值），旧视图只用 `request.GET.get("ids")` 读第一个，
**结果只能对比 1 家**，看起来像“没生效”。

### 改动
1. 视图 `chart_compare` 改用 `request.GET.getlist("ids")`，并支持逗号串、自动去重、上限 4 家；
2. 对比页顶部新增选择区：
   - 搜索框（回车/按钮）→ 结果列表「+ 添加」；
   - 无关键词时推荐「高风险前 8 家」，点「+ 添加」；
   - 已选企业显示为芯片，点 ✕ 移除；
   - 「清空重选」一键回到空态；
3. 选够 2 家立即出雷达图、分组柱、指标对照表；不足 2 家给出黄色提示；
4. 企业列表的勾选入口保留（批量对比仍可用），两条路都通。

### 验证
| 检查 | 结果 |
| --- | --- |
| 65 个测试 | 全过（新增 ComparePickerTests 6 个） |
| `?ids=1&ids=2` 多值 | 两家都出现在页面（回归测试覆盖） |
| 搜索“重庆” | 返回匹配企业并可添加 |
| 无关键词 | 显示高分推荐 8 家 |
| 1 家 | 提示“至少选择 2 家” |
