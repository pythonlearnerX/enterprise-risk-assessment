## 六、关键结论（后续课直接引用，不要重新推导）

| 结论 | 数值 |
| --- | --- |
| 企业类别 | 10000 条全为 E，**没有 P** |
| 经营状态 | 1 在营 6146、2 注销 2687、3 吊销 1167 |
| 空列 | 企业表 17 列全空（行业、经营范围、地址等）；`emp_num` 仅 550 条且有“人”字 |
| 注册资本 | 企业表 `reg_cap` 缺 11.06%；风险表 `zhuce_money` 缺 63.35% |
| 12 项指标 | 0~25，均值 9.47~9.54（被执行 6.62），**全零企业 0 条** |
| 表关联 | 按 `id` 匹配率 99.69% |
| 字符集 | 库与表 utf8mb4；MySQL 服务器默认仍为 latin1，连接必须显式 `charset=utf8mb4` |

## 七、遗留问题与下一课衔接

- **遗留 1**：MySQL 仍为 5.7.30；Django 6.1 需 MySQL 8.4+，项目 4 前必须装 8.4 到 3307（见 `docs/环境对照表.md`）。
- **遗留 2**：企业类别无 P、12 项指标无全零，与指导书描述不符，项目 12 评分方案需按实际分布设计。
- **遗留 3**：项目路径含中文与空格，指导书要求纯英文；目前无异常，出现编码/路径错误时优先怀疑此项。
- **下一课前置**：项目 4 开始前完成 MySQL 8.4（3307）安装与连通性测试；依赖如需 `requests` 等，按需补装并更新 `requirements.txt`。
