## 三、七章正文可以怎么写（每章 3–5 段的节奏）

### 1 需求分析
- 一段业务背景（中小企业风险评估的数据分散、人工判断不稳定）；
- 一段功能需求（六模块，用表格列，别写成散文）；
- 一段非功能需求（权限分级、响应时间、可复现性）；
- 一段「本项目的取舍」：只做重庆、只做一期数据、AI 不参与打分。

### 2 系统设计
- 分层图（可放 `课次/项目03-系统设计/图/` 里现成的架构图）；
- E-R 图 + 11 张表（`docs/ARCHITECTURE.md` 有简表）；
- 评分模型：12 项指标 → 四维 → 总分，写清「两种口径」（count 扣分制 / points 风险点）；
- 权限设计：`admin_required` 的三层拦截（菜单 / 视图 / 审计）。

### 3 系统实现
每模块一小节，**固定四段式**：要解决什么 → 关键代码（10–20 行，别贴整文件）→ 页面截图 → 遇到的问题与修法。
「遇到的问题」直接用 `docs/RUNBOOK.md` 第三节那 8 条，都是真实的。

### 4 数据与模型
- 数据集来源与字段（12 项指标含义）；
- 清洗规则（去重、区划码、资本单位统一）；
- 评分实现与验证（改分后等级同步、单调性）；
- **必写**：四维共线（α=0.988）与我们的应对（保留等权、写进局限）。

### 5 系统测试
直接引用 `课次/项目16-系统测试报告/` 的表格：六模块汇总、性能三项、安全十二项、缺陷九条、遗留五条。
注意：**不通过的用例必须关联缺陷编号**，不要只写「已修复」。

### 6 部署与运行
- 环境（Python/MySQL 版本、端口）；
- 容器化：Dockerfile 四段式（基础镜像 / 依赖层 / 代码 / 健康检查），首构建 6 分 20 秒、镜像 198 MB；
- 故障演练 V-01~V-08（停容器、改词库、端口冲突、镜像缺失），每次都给现象 + 处理。

### 7 总结与展望
- 完成情况对照需求（表格打勾）；
- 创新点四条：分数可复算（模型只解释不打分）、权限在后端、看板结论现算（含反直觉发现）、交付可复现（80 用例 + 实测数据 + 镜像）；
- 局限六条（照抄 `README.md` 第六节，别美化）；
- 展望：真实历史归档、因子分析降权、生产级部署。

## 四、摘要模板（改数字即可）

> 本系统面向中小企业风险核查场景，基于课程提供的重庆市企业登记与风险数据（企业 10000 条、风险记录 10000 条），
> 采用 Django 6 + MySQL 8.4 构建 Web 应用，实现企业信息管理、风险评分、数据可视化、权限分级、报告导出与大模型辅助分析六大模块。
> 评分模型以 12 项风险指标为基础，按财务、经营、合规、质量四维合成，并以 60/80 阈值划分风险等级；
> 系统同时提供 8 视角统计分析看板，用于检验数据分布、集中度与维度独立性。
> 实测表明：渲染 10000 条数据的列表页中位响应 74 ms，N+1 查询由 23 条优化至 1 条，自动化用例 80 条全部通过。
> 分析发现四维指标高度共线（Cronbach α=0.9877，第一主成分解释 96.43%），且等权权重与主成分权重一致（25.0/25.1/25.0/24.9），
> 说明现行等权合成方式在统计上是合理的；同时经营状态与风险等级无显著关联（χ²=1.72，p=0.787），故系统未设置基于经营状态的预警规则。
> **关键词**：企业风险评估；Django；四维评分；主成分分析；卡方检验；Docker

## 五、不能写的话（会被追问或判为不实）

| ❌ 不要写 | ✅ 改成 |
| --- | --- |
| 「系统可支撑高并发生产环境」 | 「开发服务器在 50 并发下错误率 18%–22%，生产需换 gunicorn/waitress」 |
| 「风险逐年上升」 | 「近年评分为演示模拟值，不用于趋势结论」 |
| 「AI 参与风险评分」 | 「AI 只做解释，分数由规则计算，可复算」 |
| 「四维是四个独立风险维度」 | 「四维高度共线（α=0.988），不可当四个独立风险源解读」 |
| 「模型准确率 95%」 | 本项目没有监督学习模型，不写准确率；要写就写「与人工标注对比的抽检结果」并给出样本量 |
| 「数据来自真实企业」 | 「数据由课程方提供，含模拟成分，仅用于教学」 |

## 六、排版建议

- 代码用 Consolas 9pt、灰底、行号可省；
- 每张图下面写「图 X-Y 说明」，并在正文里先引用（「如图 3-2 所示」）；
- 数字与单位之间留空格（74 ms、10000 条、198 MB）；
- 图表中的数据要能追溯到 `docs/STATISTICS.md` 或测试报告，别出现两处不一致。
