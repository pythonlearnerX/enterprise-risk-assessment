## 五、关键设计决策

| 决策 | 理由 |
| --- | --- |
| 用例图不画 include/extend 连线 | 聚合为 8 个用例后连线易压盖、误读；语义放在用例描述与需求条目 |
| 评分按分位数分级 | 项目 1 实测 12 项指标 0～25、无全零企业，与“扣分制”假设不符 |
| 增加 UX 章节与原型 | 需求文档只写“有什么功能”不足以指导界面开发，补信息架构、状态设计与可验收的 UX 条目 |
| 非功能需求 11 条 | 指导书要求 ≥8；补充可访问性（对比度、不只靠颜色）与脱敏要求 |
| 数据提前入库 | 便于项目 3/4 直接基于真实数据设计表结构与接口 |
