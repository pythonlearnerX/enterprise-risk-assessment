## 五、悬停截图是怎么来的

ECharts 的 tooltip 由鼠标事件触发，无头浏览器没有真实鼠标。预览页在图表初始化后调用：

```js
chart.dispatchAction({type: "showTip", seriesIndex: 0, dataIndex: 0});
```

对饼图（在营）和柱图（100–500 万）各触发一次，再截图，得到的就是真实 tooltip 渲染效果，不是画上去的。

> 注意：预览页里 `</body>` 往正文插脚本时，必须用最后一个 `</body>`；ECharts 压缩代码里也有 `</body>` 字符串，误替换会把库打断，表现为整页空白。这次踩过。

## 八、风险评分函数与 PDF 报告（2026-11-17）

### 1. `risk_app/risk_calc.py`

按 PPT 的扣分制实现，四维各 25 分、合计 100：

```
count 模式（事件次数）：
  维度平均 = (近1年 + 近2年 + 近3年) / 3
  维度得分 = clamp(25 - 平均次数 × 1, 0, 25)
  总分     = Σ 维度得分 × 0.25 × 4

points 模式（当前数据集，0–25 风险点）：
  维度得分 = clamp(平均风险点, 0, 25)
  总分     = Σ 维度得分 × 0.25 × 4
```

- 等级：<60 低、60–80 中、≥80 高；
- 年度权重、维度权重可传参（默认等权）；
- 单维不为负、总分 [0,100]。

### 2. 预览命令

```bash
python manage.py score_preview --limit 5
```

只读，不修改数据库；输出两种口径的分布与前 N 家对比。

### 3. PDF 报告

- 路由：`/enterprise/<id>/report.pdf`
