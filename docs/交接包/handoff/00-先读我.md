# 先读我（给接手的人 / AI）

这是一个课程实训项目「企业风险评估系统」的交接包。仓库版本见
https://github.com/pythonlearnerX/enterprise-risk-assessment

## 包里有三样东西

| 路径 | 内容 |
| --- | --- |
| `项目上下文-单文件.md` | **一个文件看完整个项目**：说明、规约、架构、跑通、测试、统计口径、报告指引、PPT 复盘、提示词（约 73 KB） |
| `文档/` | 上面那份单文件的各分册（想看哪份看哪份） |
| `代码/` | 后端源码（models / views / urls / risk_calc / analytics / abtest / ai_service / report_pdf / 配置），不含模板与静态库 |
| `课次/` | 17 个课次的文档（md） |

## 怎么用

- **只想让 AI 看懂并给建议**：把 `项目上下文-单文件.md` 整个上传，按 `文档/AI-PROMPTS.md` 里的提示词提问；
- **要跑起来**：看 `文档/RUNBOOK.md`，注意数据库连接走 `.env`（模板在仓库 `.env.example`）；
- **要改 PPT**：看 `文档/PPT-REVIEW.md` + `文档/AI-PROMPTS.md` 的提示词 B；
- **要写实训报告**：看 `文档/REPORT-GUIDE.md` + 提示词 C。

## 两个必须先知道的约束

1. 代码里的数字（基尼 0.3936、α 0.9877、χ² 1.72 等）都是 10000 条真实数据的实测值，`文档/STATISTICS.md` 是唯一来源，**不要自己编**；
2. 「近年评分」是模拟数据（0.90/0.95/1.00 等比缩放），只用于演示趋势组件，不能用于任何结论。
