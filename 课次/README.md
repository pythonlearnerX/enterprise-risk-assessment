# 课次总目录

> 本文件是「每一次课」的入口。新课开工**先读这里**，再读上一课的 `README.md`，按顺序接续。
> 原则：一课一个目录，只增不改；共享资源只读；每课都有独立产出、截图与提交包。

## 目录约定

```text
课次/
├─ README.md                    # 本文件：索引 + 开工/收工流程
├─ 课程总览.md                   # 15 个项目清单、状态、依赖关系
├─ _模板/                       # 新课模板（复制后改名）
│  └─ README.md
└─ 项目01-环境安装与数据集梳理/    # 每个项目一个目录
   ├─ README.md                 # 本课目标、输入、产出、验收、衔接
   ├─ 报告/                     # docx / pdf
   ├─ 截图/                     # 提交用截图
   ├─ 日志/                     # 脚本运行输出
   ├─ 原始输出/                 # 截图对应的命令原文
   └─ 提交/                     # 学号-姓名-项目N.zip
```

## 每课开工流程（我按这个执行）

1. 读 `课次/课程总览.md`，确认当前进度与下一课编号；
2. 读**上一课** `课次/项目NN-.../README.md` 的“产出 / 衔接点 / 遗留问题”；
3. 读 `docs/参考资料/` 里新下发的指导书（原件放这里，不改动）；
4. 读 `docs/环境对照表.md` 与 `dataset/README.md`，确认环境与数据口径没有变化；
5. 复制 `课次/_模板/` 为 `课次/项目NN-课程名/`，先写 README 的目标与验收标准，再动手；
6. 本课代码放 `课次/项目NN-.../code/`（课程要求放根目录的除外），共享数据仍用根目录 `dataset/`；
7. 产出写进本课目录，完成后更新本课 README 与 `课程总览.md`。

## 每课收工流程

1. 本课 README 补：完成情况、产出清单、验收证据、遗留问题、下一课衔接；
2. `课程总览.md` 状态改为 ✅，填产出目录与日期；
3. 根目录 `README.md` 的“当前进度”同步；
4. 当天工作日志 `01_工作日志/YYYY-MM-DD.md` 记录；
5. 回读校验：README 非空、关键路径存在、截图能打开。

## 不干扰原则

| 规则 | 说明 |
| --- | --- |
| 一课一目录 | 新内容只写进本课目录，不回头改上一课的文件 |
| 共享只读 | `dataset/`、`docs/参考资料/`、`.venv/`、`requirements.txt` 默认只读 |
| 共享变更要留痕 | 必须改依赖或环境时，在本课 README 写清“为什么改、影响谁”，并更新 `docs/环境对照表.md` |
| 提交包独立 | 每课 `提交/` 只放本课压缩包，不覆盖别课 |
| 代码分界 | 根目录只放课程强制要求的脚本（如 `dataset_process.py`）与后续 Django 工程；课内试验代码放本课 `code/` |
